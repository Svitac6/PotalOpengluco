# OpenGluco – Frontend

Frontend of the **OpenGluco** application, built with **React**, **Vite**, **Tailwind CSS**, and **TypeScript**.

---

## 📌 About

OpenGluco is an open-source platform designed to centralize and visualize blood glucose data.  
This repository contains only the **frontend** (user interface) part of the application.

---

## 🛠 Tech Stack

- **[React](https://react.dev/)** – JavaScript framework for building UIs.
- **[Vite](https://vitejs.dev/)** – Fast build tool and development server.
- **[TypeScript](https://www.typescriptlang.org/)** – Typed superset of JavaScript.
- **[Tailwind CSS](https://tailwindcss.com/)** – Utility-first CSS framework.

---

## 🚀 Installation & Usage

```bash
# 1. Clone the repository
git clone https://github.com/your-organization/opengluco-frontend.git

# 2. Go to the project folder
cd opengluco-frontend

# 4.  Go to the frontend
cd frontend

# 3. Install dependencies
npm install

# 5. Start development server
npm run dev

```
